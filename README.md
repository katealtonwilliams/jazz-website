# Tanner and the Tones

A responsive static website for Manchester big band Tanner and the Tones. No build step
or package installation is required.

## Run locally

From this directory, start a local server:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Gig calendar

The Gigs section is a placeholder for a public Google Calendar embed. Once the band has
a public calendar, add its embed URL in `index.html`. Until then, the section links to
the band's official Linktree for current show information.
